# ☕ Coffee Sales Dashboard — Sales Trend & Time-Based Performance Analysis

This project was developed as part of a **Data Analyst Internship**, focusing on analyzing coffee shop sales data to uncover customer purchasing behavior across time, day, and store locations.

The dashboard helps identify peak hours, busiest days, and high-performing stores to support **data-driven business decisions**.

---

## 📊 Project Overview

This dashboard provides insights into:

- Hourly customer demand patterns  
- Revenue trends across days of the week  
- Store-wise performance comparison  
- Top-selling products by revenue  
- Time-of-day sales distribution  
- Interactive heatmap for demand visualization  

The goal is to help businesses optimize staffing schedules, inventory planning, store operations, and sales strategies.

---

## 🚀 Features

- Interactive filters (Store location & Hour range)

## ▶️ How to Run Locally

1. Clone the repository
```
git clone https://github.com/yourusername/coffee-sales-dashboard.git
```

2. Navigate to project folder
```
cd coffee-sales-dashboard
```

3. Install dependencies
```
pip install -r requirements.txt
```

4. Run Streamlit app
```
streamlit run app.py
```

📌 For detailed Streamlit setup guide:  
https://docs.streamlit.io/get-started/installation
